# Публичный каталог CanAI

Этот каталог поставляется вместе с локальным CanAI и не обращается к инфраструктуре команды. Идентификаторы, параметры, пары операций и перевод в fal принадлежат этому выпуску. Командный сервер закрепляет копию того же выпуска и отдельно хранит собственные маршруты, публикации и цены для участников.

Обновление — явная замена выпуска. `scripts/catalog-release.mjs` создаёт манифест SHA-256; `--check` сверяет файлы с закреплённым манифестом. Старый клиент не обязан совпадать с последним выпуском: проверяется `minExecutorVersion` конкретной модели. Дополнения пользователя не входят в обновляемую папку.

Flare/Sunburst проверены по четырём схемам fal 09.09.2026:

- https://fal.ai/models/openai/gpt-image-2.5/flare/text-to-image/api
- https://fal.ai/models/openai/gpt-image-2.5/flare/edit/api
- https://fal.ai/models/openai/gpt-image-2.5/sunburst/text-to-image/api
- https://fal.ai/models/openai/gpt-image-2.5/sunburst/edit/api

Тариф этих моделей токеновый; опубликованные примеры стоимости отдельных размеров не являются фиксированной ценой произвольной генерации. Платный пробный запуск этим выпуском не подтверждён.
