# CanAI tablet guide

The tablet and computer must be on the same Wi‑Fi network, and CanAI must be running on the computer.

## Connect

On the computer, open **Settings → Tablet access**, set a 4–12 digit code, and enable access. CanAI shows an address such as `http://192.168.1.5:8789`.

On the tablet, open that address in Safari and enter the code. Use **Share → Add to Home Screen** if you want an app icon. The tablet layout works in landscape orientation.

## Tablet controls

- Drag an empty area to move the board; drag an object to move it.
- Pinch to zoom.
- Press and hold for the object menu.
- Swipe with three fingers left or right to undo or redo.
- Drag an object to the shelf to pin it, or to the Archive tile to remove it from the board.
- The top bar, shelf, and Archive are on the left; the Inspector is on the right; Prompt and Assistant are at the bottom.

Work started on the computer continues on the tablet. Macro runs are executed by the local backend, so the tablet can be locked while a run continues.

The tablet intentionally does not include the Workflow/Macro editor, assistant profile editor, external-editor launch, fal.ai key entry, or publication creation. Use the computer for those actions.

If the board stops saving, the tablet lost its connection to the computer. To revoke tablet devices, use **Settings → Tablet access → Disconnect devices** and change the code.
